# Recurring public-web research — stage 4c

Status: VERIFYING. Release 1.18, scoped MV2-019/021/023 continuation.

An editor deliberately submits a public-search question and daily or weekly
cadence. A separate standing policy works for private drafts, member teams and
workspace dossiers. Saving a search elsewhere is not recurring consent. The
policy uses the account's current dossier editor authority after signout; no
session is manufactured. The dossier audience is pinned and never published.

Each occurrence is committed with one durable investigation before network work.
The existing coordinator reserves the shared query budget and persists each
in-flight request before calling providers. Interrupted requests are not repeated
automatically. A later cadence is a new occurrence, not a retry or catch-up burst.
An explicit retry consumes the same two-starts-per-UTC-day policy limit. Saving
settings does not reset usage. Pause/revision/role/audience fences apply around
network calls. A policy change cancels unfinished work; completed evidence stays.

One submitted question per occurrence; no private-text query generation or
entity expansion. Existing balanced Google/Bing and Pharma Europe PMC retrieval
uses Jev/TypeSafe with Laya fallback. At most three permitted anonymous source
reads lead to at most three independent extractions and one comparison with
same-audience prior claims. Search snippets are never evidence. Existing robots,
size, source exclusions and access barriers apply. No new notification subscription
or source approval is inferred. Monetary cost is not a hard currency cap; actual
latency, configured token-cost estimates and unmetered costs remain explicit,
with provider confidence distinct from independent accuracy.

Captured URL/body/selected-excerpt fingerprints are compared to the latest
successfully analysed capture for the same question. Unchanged captures remain
inspectable but skip extraction. A changed question or changed/reappearing source
is analysed again. Failed extraction never establishes a duplicate baseline.
A complete empty search is a recorded no-new-evidence outcome; provider failure
remains unavailable. Source reads and ranking still cost work on unchanged pages.

Both products preserve the Brandbook tokens and evidence-first dossier sections.
A dedicated recurring-search section offers question, cadence, unchecked consent,
pause, actual schedule/usage, paginated occurrences and links to live evidence.
No browser interaction or human visual acceptance is claimed by background checks.
