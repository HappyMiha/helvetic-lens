# Global Ask/Search and retained command drafts

Status: DONE — scoped production release 1.24 under MV2-002/023/024. Scope,
dependencies, source readiness and acceptance were recorded before code in the
sole Monitoring backlog. The full dynamic/visual specifications and broader
MV2 tasks remain IN PROGRESS.

The native platform now places one Ask/Search entry below the root authorization
boundary, including login and assistant history. Cmd/Ctrl+K opens the existing
Radix dialog; repeated/composed/handled or differently modified keys and other
dialogs keep their keyboard ownership. The entry and dialog use Brandbook reading
tokens, five locale dictionaries, forced-color/reduced-motion behavior and mobile
navigation clearance. This extends the delivered native identity and themes.

An explicit search reads either current-authority saved registry records
(monitored sources and discovered events) or the two products' author-published
public knowledge. Collections retain independent failure/empty states, a bounded
20-item window, real totals only where the API supplies them, full-collection
links and validated source/evidence anchors. Native saved/public matching remains
literal. This release does not widen internet coverage or replace the products'
existing semantic saved-evidence retrieval and deliberate public-web research.
Typing makes no request. Existing APIs remain authoritative for access.

On pages that mount Marvin, a question can be prepared in its existing private
conversation/comparison draft. A different existing draft causes a visible
conflict and remains intact. Paused/detached, still-loading or busy context stays unavailable. A pending
conversation cannot accept a new prepared draft that a late failure could
replace when restoring its previous question. Preparation does not submit inference, change preferences, reattach
context or create a second assistant. The existing private draft mechanisms are
reused, including their normal autosave. Focus transfers only after the command
closes and only while the same context is still mounted.

Both product commands retain questions on dismissal, recheck account access
before displaying a retained draft, and clear command state on page, dossier,
account or role transitions. Native command state also clears on locale and
authentication changes. Keyed command children preserve the surrounding research
and Marvin components. Aborts/attempt epochs fence late search/session responses.
Uncertain product provider receipts remain in the parent for same-query recovery;
this never carries a draft or results into another account.
