## Implemented working contract

- The hosted model receives numbered exact original quotation windows. Short table
  cells remain visible; long passages are covered with overlapping windows. Canonical
  source permissions, source hashes and field-specific citation checks remain intact.
- Planning receives the user question and available source capabilities without the
  unrelated professional metadata bundle. Section reading selects original evidence
  rather than rewriting stored claims. Existing claims cannot contaminate new reading.
- Whole-document/tree reviews use separately scoped source and target references.
  Missing cross-reference target passages deterministically remain unresolved.
- Final synthesis selects required evidence references before writing each answer point and produces one cited mission answer. A fully answered question may have no unresolved gaps; the contract does not require inventing one. The server derives the existing
  dossier presentation and pinned question assessments from that same answer. Optional
  enrichment cannot erase a valid document section. Repair receives precise field paths.
- Compact original pages retain headings, dates, bibliography labels and neighbouring
  qualifications. Large documents retain selected original observations across all
  section and reconciliation stages. Navigation-only discovery links and source-owned link ranking metadata are not repeated
  in synthesis; canonical source permission/hash fences remain unchanged.
- A final review receives a separate evidence-focused input. Jev/Laya additionally
  check individual assertions against their selected quotes and look for counterexamples
  to proposed limitations across the current synthesis windows. Large documents may
  supply selected observations after full section reading/reconciliation; this additional
  audit is not an exhaustive second verification of every saved page. It is limited
  to the authorized public exploration pack; it cannot transmit contributed/private
  material. Unavailable or incomplete audit coverage stays explicit. Its decisions are
  correction hints, not evidence, verified truth or calibrated accuracy.
- Reported final quantities must occur in selected original windows; digit grouping
  is normalized, never guessed decimal conversion. This check does not prove semantic
  entailment or unit-pair consistency. A known-invalid response cannot escape validation
  merely because no repair time remains. A failed final answer is retryable failure,
  never a completed mission with an empty answer.
- Safe canonical redirects check each target's robots policy and source exclusions,
  omit cookies, and preserve requested/final addresses. Public main text survives a
  peripheral sign-in widget. Source-owned links are discovery leads, never evidence.
- Multipart requests have required response sections tied to the user's literal
  sentences, including short follow-ups. Each section supplies cited points or an
  explicit unresolved part before flattening to the existing dossier API. Empty
  sections cannot masquerade as answered. More than eight sentence fragments are
  grouped without discarding text. This is structural coverage, not proof that the
  generated interpretation or answer is correct.
- A missing dated context window can be recovered from the same already-cited original
  only after a focused entailment check. Remaining quantity errors get a small,
  one-point correction with local reference IDs, the exact user-request binding and
  short numerical original context; later format repair retains corrected
  points rather than reverting to the old draft. This reduces repeated full synthesis.
- A witnessed link to a materially needed original can reopen reading before finish.
  An exact public URL goes directly to the normal source reader, without unrelated
  web/catalogue searches; prose containing URLs retains ordinary discovery. Empty
  observation reviews have a valid provider schema and cannot invent citations.
  Optional original routing respects the remaining deadline before each fallback.
- Native jobs preserve source reading across temporary inference failures with delayed
  retries of the same input. Duplicate delivery, pause, revocation and changed evidence
  retain their fences. Three automatic retries of a failed operation do not impose a
  total research budget; later explicit retry retains the same saved originals. Legacy
  monitoring start/retry authorization is unchanged.
