the server-bound branch/question/purpose/effective query and prior public queries.
Its optional assessment reuses exact citation and evidence-role validation; a
missing result stays unknown. The legacy evidence_found field is unchanged.
All assessment/proposal validation precedes question writes. A further check is
sealed with the exact target, supplied public claims and full accumulated source
dependencies, including transitive read context that was not quoted or directly
supplied to reflection; it never becomes an automatically scheduled branch. Normalized
query reuse is rejected, including typed ancestors and existing gap proposals.

same question. Current strict receipts, read dependencies, revisions and typed ancestry fence replies,

while permitting independent research; changed statements, private backing, source
versions or rights still stop dependent work. No obsolete assessment is supplied
to the final briefing. Internal receipts are omitted from API and saved plans.

and limits. Missing outcomes stay unknown; outdated public-context assessments
are marked for fresh review. The existing one-button continuation remains separate
from monitoring. No new route, form, polling loop, default inference or schema.
