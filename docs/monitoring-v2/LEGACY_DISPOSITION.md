# Monitoring v2 — перенесення незавершених зобов’язань

**Перевірено 35 non-DONE пунктів** індексу попереднього беклогу на `7109a28`. [Оригінальний backlog](../../BACKLOG_V1_ARCHIVE.md) збережено без зміни його статусів чи acceptance. Це історичний доказ; нова робота виконується лише за [MV2 backlog](../../BACKLOG_MONITORING_V2.md).

**Правило успадкування:** перша задача в кожному рядку відповідає за координацію повного залишку старих acceptance; інші — за вказані спільні частини. Перед DONE власник звіряє всі невиконані підкритерії оригінального HL-пункту, додає виконувані підзадачі MV2 за потреби і прикріплює докази. Мапінг не означає DONE і не дозволяє послабити старий gate. Уже зроблений код не переписується лише через зміну ID.

Наприклад, старі read p95≤500ms / enqueue≤1s, 100 акаунтів/10 організацій, 100k legal corpus/20 readers, 50-run assistant stability, human five-language/assistive-technology перевірки та Basel pilot obligations зберігаються у відповідних MV2 gates. Нові цифри для time-series навантаження не замінюють їх.
