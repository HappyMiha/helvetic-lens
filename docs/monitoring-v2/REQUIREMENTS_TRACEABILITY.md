This table maps accountability rather than reporting completion. Following the user decision in plan 1.1, 116 AC are active: 20 CORE, 60 C1/C2/C3/C5/C6/C7, 36 B2/B7/B8; all 10 AC-C4 and S-41/42/43 are DEFERRED. Partial changes to S requirements appear in the Evidence column, with their original content retained. Shared task criteria, architectural invariants and inherited legacy acceptance remain mandatory within active scope. DEFERRED does not mean DONE and does not create current work.

Multiple task owners indicate contributions to a requirement, rather than requiring every preparatory task to complete the entire AC. MV2-069 closes C5 source/product contracts, MV2-070 contributes platform/components, and final C5 source-to-user acceptance occurs in MV2-031/071. Cross-domain CORE closure belongs to MV2-057.

To close each active row, replace `NOT VERIFIED` with a specific test/protocol, fixture/source revision, commit and reviewer. A BLOCKED label, unavailable field or link-only access does not mean automatic monitoring is implemented. Each of the 116 active AC must also pass the shared MV2-057 gate. Deferred C4 AC are not its dependencies; restoring that scope requires a new explicit user decision.

**First delivery, plan 1.2:** MV2-069/070/030/031/071 accept all AC-C5 and AC-CORE within C5. Full cross-domain CORE acceptance remains in MV2-057, reusing C5 evidence. Early user testing does not close the overall v2 pilot.

**Deployment decision, plan 1.5:** [MV2-072](../../BACKLOG_MONITORING_V2.md#mv2-072) records the user's separate branch, HappyDucky02 host and monitoring.helveticlens.ch deployment requirement. Its six infrastructure criteria are additional to the original specification, so the 126 AC and 79 supplemental rows below remain unchanged. Deployment evidence belongs to MV2-072 and does not change any product-requirement status or complete Pollen Watch acceptance.
