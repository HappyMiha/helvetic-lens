## Scope, dependencies and source readiness

New exploratory episodes supply current, question-specific read assessments to
the existing reflection and early-orientation requests. Preserve early scheduling,
its timeout and all existing budgets; do not wait for every extraction or add a
model request. Original user wording remains authoritative. Assessments describe
captured passages, not factual truth, human acceptance or settled intent. An
unrelated passage for one question may help another. Preserve useful context,
counterevidence, uncertainty, missing assessments and incomplete-reader limits.

Reuse read-relevance/v1, the existing branch state, current public source versions,
exact citations, adaptive dependency guards, orientation/reconsideration/selected
question contracts, worker leases and client reader. No new schema, provider,
query phase, automatic episode, setup fields or monitoring authority. Opt in new
episodes; old exploration and other private/legacy workflows stay compatible.

Reflection input must exclude claims with private, excluded or unsupplied backing
sources. Pin all supplied sources, question assessments and claim context through
completion. Validated derived follow-ups retain complete source dependencies even
when there was no early orientation or no reconsideration. Revocation must stop
later derived work and hide dependent output. Invalid quotes and stale orientation
revisions remain rejected atomically. Snapshot early assessment availability so
history never claims later analysis had already informed an earlier checkpoint.
Both readers expose that small preparation note in existing citation details.

Existing configured search/reader/model contracts are available. Source readiness
is not live quality validation. Use durable scripted evidence and existing reader
fixtures only; no paid/live research, private production data, browser/preview,
new credentials or frozen validation. Preserve Brandbook, nine routes and Apache-2.0.

## Implemented contract

New episodes opt into read-informed-research/v1 alongside read-relevance/v1.
product_informed_research builds a request-local context containing only assessments
whose exact source version, question and quote match supplied public passages.
It preserves multiple question-specific assessments of one source, exact typed
limitations, known/unknown reader truncation and explicitly unassessed sources.
The existing Reflection/EarlyOrientation request and response schemas, scheduling,
timeout and budgets remain unchanged; there is no additional default inference.

Reflection claim context is restricted to claims wholly backed by the supplied
public sources. Before applying a response, the source versions, assessment
snapshot and supplied claim statements/status/access are checked again. Every
successful reflection retains its source dependencies through the existing
adaptive fence, including reflections without an early view or reconsideration.
Exact gap citations and early revision validation still precede all question writes.

Early interpretation retains its internal read-context snapshot and exposes only
small server-derived assessment-availability counts to the reader. Later extractions
do not rewrite those counts. Both clients place the explanation in closed details
beside the original tentative interpretation. Source quotes, model interpretation
and human acceptance remain separate; history starts no work. Existing source and
ancestry invalidation hides dependent output. Older episodes remain compatible.
