assessment emits question_assessment_saved through the existing event writer in
the apply transaction. Its server event sequence and saved time enter the sealed
assessment receipt, without model control. Later final renewal retains the old
receipt in history and uses its existing final-brief identity. No new request.

The existing assessment projection validates all source/claim/read/target and
ancestry dependencies. The working exploration projects only the latest eligible
saved identity, ordered by its event sequence, referencing that existing content.
When a later assessment becomes outdated, an older still-valid assessment may be
shown with its original saved date. Unavailable rights/changed statements or hashes
withhold dependent text. No legacy timestamp is synthesized; final briefings take
over the primary display. Public research/plan records exclude internal receipts.

Both working readers promote that single cited question, folding earlier context
and excluding the promoted question from the existing secondary list. Saved history,
paused/cancelled work and unavailable final briefings reuse this reader. Citation
roles, quotes, links and limitations reuse QuestionCheckpointContent. There is no
live announcement, focus/scroll effect, extra form or polling loop. ResourceReader
already rejects obsolete request generations and clears data on failed authority.
